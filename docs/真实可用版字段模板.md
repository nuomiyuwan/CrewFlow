# CrewFlow 真实可用版字段模板

这份模板用于把旧的“年度工作安排表”转成 app 内的标准录入方式。旧表不再继续使用，但它反映了公司真实项目管理习惯：按项目、月份、人员、工序、反馈和交付节点来推进。

核心原则：尽量用下拉选择、日期选择、人员选择和状态按钮，减少人工写长文本。

## 1. 项目基础信息

新建项目时由总控或管理员填写，项目经理收到后继续完善。

| 字段 | 录入方式 | 说明 |
| --- | --- | --- |
| 项目名称 | 手动输入 | 必填，作为项目主标题 |
| 客户单位 | 下拉选择 + 可新增 | 例如北京公司、平谷公司、新疆公司 |
| 项目类型 | 下拉选择 | 短视频、纪录片、总结片、宣传片、微电影、平面设计、其他 |
| 项目负责人 | 人员选择 | 总控/管理员指定项目经理 |
| 项目状态 | 下拉选择 | 未开始、进行中、等反馈、修改中、已交付、暂停、归档 |
| 优先级 | 下拉选择 | 普通、重要、紧急、高风险 |
| 计划开始时间 | 日期选择 | 可选 |
| 计划交付时间 | 日期选择 | 必填，进入交付日历 |
| 项目文件夹 | 路径选择 | 指向群晖 NAS 项目目录 |
| 项目备注 | 文本 | 只写特殊说明 |

## 2. 项目阶段模板

项目经理在项目中心选择当前阶段。阶段变化后，首页和交付日历同步更新。

| 阶段 | 适用项目 | 常见输出 |
| --- | --- | --- |
| 需求对接 | 全部 | 需求记录、参考资料 |
| 策划方案 | 视频/活动/宣传片 | 策划案、创意方向 |
| 脚本撰写 | 视频类 | 脚本、解说词 |
| 拍摄筹备 | 视频类 | 拍摄计划、通告、外包确认 |
| 拍摄执行 | 视频类 | 原始素材 |
| 素材整理 | 视频类 | 素材归档、可用素材标记 |
| 初剪 | 视频类 | 初剪版本 |
| A-copy | 视频类 | A-copy 审看版本 |
| 修改中 | 全部 | 修改版本 |
| B-copy | 视频类 | B-copy 审看版本 |
| 内部审核 | 全部 | 内部审片/审稿意见 |
| 客户反馈 | 全部 | 客户反馈记录 |
| 成片交付 | 视频类 | 成片文件、交付记录 |
| 复盘归档 | 全部 | 归档文件、复盘备注 |

## 3. 人员分工与任务

项目经理不再手写“策划：某某、剪辑：某某”，而是在项目内添加任务。

| 字段 | 录入方式 | 说明 |
| --- | --- | --- |
| 所属项目 | 自动带出 | 来自当前项目 |
| 工种 | 下拉选择 | 项目经理、策划、文案、拍摄、剪辑、后期、包装、设计、AI、外包 |
| 执行人 | 人员选择 | 可选内部成员或外包人员 |
| 任务名称 | 下拉选择 + 可补充 | 例如脚本撰写、A-copy 修改、包装制作 |
| 任务状态 | 下拉选择 | 未开始、进行中、等反馈、已完成、卡住 |
| 截止时间 | 日期/时间选择 | 进入“我的任务”和交付日历 |
| 是否关键任务 | 开关 | 关键任务进入首页必盯 |
| 备注 | 文本 | 只写非标准内容 |

任务生成规则：

- 总控/管理员新建项目并指定项目经理。
- 项目经理在项目中心拆任务并指定执行成员。
- 执行成员登录后，只在“我的任务”看到自己被指派的任务。
- 执行成员更新任务状态后，项目经理、管理员、总控能看到同步变化。

## 4. 交付节点

交付日历不再只写 A-copy、成片，而是显示“哪个项目在当天进行到哪一步”。

| 字段 | 录入方式 | 说明 |
| --- | --- | --- |
| 所属项目 | 自动带出 | 当前项目 |
| 节点类型 | 下拉选择 | 脚本、拍摄计划、拍摄、A-copy、B-copy、成片、设计稿、资料确认、客户审片、复盘 |
| 节点名称 | 自动生成 + 可改 | 例如“星河商业广场招商宣传片 A-copy 二轮修改” |
| 计划时间 | 日期/时间选择 | 必填 |
| 实际完成时间 | 日期/时间选择 | 完成后填写 |
| 负责人 | 人员选择 | 通常是项目经理或对应执行人 |
| 节点状态 | 下拉选择 | 未开始、进行中、等反馈、已完成、延期 |
| 关联任务 | 任务选择 | 可选，用于自动联动 |

日历显示规则：

- 总控/管理员：看到全部项目节点。
- 项目经理：看到自己负责项目的节点。
- 执行成员：只看到与自己任务相关的节点。
- 财务：可看到与收款、开票、合同相关的节点。

## 5. 反馈与修改

旧表里的“反馈”“状态”“备注”统一转成项目动态。

| 字段 | 录入方式 | 说明 |
| --- | --- | --- |
| 所属项目 | 自动带出 | 当前项目 |
| 动态类型 | 下拉选择 | 工作安排、客户反馈、内部反馈、状态变化、风险、备注 |
| 来源 | 下拉选择 | 内部、客户、领导、外包、其他 |
| 修改轮次 | 下拉选择 | 一轮、二轮、三轮、四轮以上、不适用 |
| 当前状态 | 下拉选择 | 待处理、处理中、已提交、等确认、已关闭 |
| 内容 | 文本 | 只写具体反馈 |
| 关联节点 | 节点选择 | 可选 |
| 关联人员 | 人员选择 | 可选 |

风险识别关键词：

- 暂停
- 信息不同步
- 客户未确认
- 等反馈
- 逾期
- 多轮修改
- 人员未定
- 外包未确认

这些内容后续可以自动进入首页“今日必盯”和“风险项目”。

## 6. 素材与文件

素材库围绕群晖 NAS 项目目录设计。

| 字段 | 录入方式 | 说明 |
| --- | --- | --- |
| 所属项目 | 自动带出 | 当前项目 |
| 文件类型 | 自动识别 + 可改 | 原始素材、工程文件、A-copy、B-copy、成片、设计稿、资料 |
| 文件路径 | 自动读取 | 来自 NAS |
| 拍摄日期 | 日期选择 | 可选 |
| 拍摄人员 | 人员选择 | 可选 |
| 是否可用 | 下拉选择 | 可用、备用、废弃、待确认 |
| 备注 | 文本 | 可选 |

素材预览规则：

- 点击视频素材直接预览原始视频。
- 不单独设计“低清预览”按钮。
- 后续可考虑自动生成缩略图和代理预览，但第一版不强制。

## 7. 财务结算

财务页只给财务、管理员、总控使用。第一版不显示利润和毛利。

| 字段 | 录入方式 | 说明 |
| --- | --- | --- |
| 所属项目 | 自动带出 | 当前项目 |
| 报价是否制作 | 下拉选择 | 未制作、已制作、已发送、需修改 |
| 合同金额 | 金额输入 | 可选 |
| 合同状态 | 下拉选择 | 未签、待签、已签 |
| 甲方是否结算 | 下拉选择 | 未结算、部分结算、已结算 |
| 已收金额 | 金额输入 | 可选 |
| 未收金额 | 自动计算 | 合同金额 - 已收金额 |
| 开票状态 | 下拉选择 | 未开票、部分开票、已开票 |
| 已开票金额 | 金额输入 | 可选 |
| 外包制作成本 | 金额输入 | 可选，不进入利润展示 |
| 外包是否开票 | 下拉选择 | 不涉及、未开票、部分开票、已开票 |
| 给外包是否结算 | 下拉选择 | 不涉及、未结算、部分结算、已结算 |
| 待付金额 | 金额输入 | 可选 |
| 财务备注 | 文本 | 可选 |

## 8. 第一版建议先做的新增能力

第一版真实可用版优先做这些：

1. 项目录入表单改成标准字段。
2. 项目经理能给项目添加任务并指派执行人。
3. 我的任务由项目任务自动生成。
4. 交付日历由交付节点自动生成。
5. 项目动态替代旧表里的反馈、状态、备注。
6. 财务页使用独立字段，不显示利润和毛利。
7. 素材库关联 NAS 项目目录。

暂时不建议第一版做这些：

1. 自动识别旧 Excel 并长期导入。
2. 复杂利润核算。
3. 在线协作评论流。
4. 大模型深度接管项目判断。
5. 复杂审批流。

## 9. 后续开发顺序建议

1. 先搭真实数据库结构。
2. 再改项目录入和任务指派。
3. 再让“我的任务”和“交付日历”读取真实任务。
4. 再接 NAS 素材路径。
5. 再做财务字段。
6. 最后接本地智能助理，让它读取项目、任务和交付数据给提醒。
