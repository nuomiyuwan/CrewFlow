# CrewFlow v1.4.2

发布日期：2026 年 8 月 3 日

## 本次更新

- 在线 AI 设置支持保存多个已测试成功的常用模型配置，可在模型下拉菜单中快速切换，不必重复填写服务地址、模型名称和 API Key。
- 交付日历节点新增“完成/恢复”状态。已完成节点保留为项目历史记录，不再计入待交付和风险判断。
- 普通节点只有在“已过期且未完成”时才会使项目显示“有风险”；最终交付节点只有在“已过期且未完成”时才会使项目显示“已延期”。
- 节点完成、恢复、删除、改期或编辑后，项目状态会立即重新计算。
- 修改节点的日期、名称或所属项目时，节点会自动恢复为待完成，避免已完成的历史记录误作用于新计划。
- 助理上下文会识别节点是否已经完成，减少将历史节点误当作待办事项的情况。

## 团队模式升级建议

1. 先备份常驻主机上的团队数据库。
2. 优先更新常驻主机上的 CrewFlow，再更新其他电脑。
3. 确认团队服务正常后，测试登录、项目读取、节点完成状态和保存。
