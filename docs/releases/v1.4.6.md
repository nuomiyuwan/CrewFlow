# CrewFlow v1.4.6

发布日期：2026-08-14

## 本次更新

- 新版成功启动后，自动删除 CrewFlow 专用更新缓存中已经完成安装的安装包。
- 兼容清理旧版本下载但未记录清理标记的 CrewFlow 安装包。
- 清理前会比较安装包与当前应用版本，尚未安装的更高版本安装包会继续保留。
- 清理范围不包含系统下载目录、项目数据、团队数据库和助理设置。
- 新增 macOS、Windows 更新缓存清理测试，覆盖旧命名、当前版本、未来版本和非 CrewFlow 文件。

## 安装包

- `CrewFlow-v1.4.6-macOS-universal.dmg`：Apple Silicon 与 Intel Mac 通用安装包。
- `CrewFlow-v1.4.6-Windows-x64-Setup.exe`：64 位 Windows 10/11 安装程序。

Windows 应用内更新还会使用同一 Release 中的 `latest.yml` 和 `.blockmap` 文件，请勿单独删除。

## 更新说明

- 团队主机建议优先更新，其他电脑随后更新到相同版本。
- 更新安装包只会在新版确认启动后清理；如果安装尚未完成，安装包仍会保留。
- 单人数据、团队数据库和助理 API Key 均保存在安装目录之外，正常更新不会清空数据。
