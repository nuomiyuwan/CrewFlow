# CrewFlow v1.4.10

发布日期：2026-08-20

## 本次更新

- 团队模式新增在线人数与在线成员列表，可查看成员角色和连接设备数量。
- 更新或启动后自动恢复团队连接并重新载入数据，不再依赖手动测试连接。
- 团队数据尚未载入时暂停新增和修改，最近同步时间在真实读写完成后更新。
- 财务账号或项目经理账号被指定为项目负责人后，可以编辑自己负责的项目。
- 归档项目负责人可在归档页调整项目状态、流程节点和最终交付日期，其他归档内容仍受保护。
- CrewFlow 助理默认收起为小图标，并优化合同文件路径排版。
