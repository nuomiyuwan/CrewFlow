CrewFlow 1.1.0 正式版。

## 本次更新

- 修复团队模式连续操作时可能出现的版本冲突，写入改为顺序保存，保存期间暂停轮询。
- 修复部分项目未显示在交付日历的问题，并防止误删项目最后一个交付节点。
- 已有项目的任务可在“编辑项目”中切换内部人员或外包执行。
- 新增独立的项目健康度；超过交付日期且尚未归档的项目会自动显示为已延期。
- “需修改”和修改中的任务不再自动判定为风险；等甲方反馈、等内部确认继续联动首页等待统计。
- 首页“拍摄/素材节点”替换为“待结款项目”，与合同金额、已收金额和甲方结算状态联动。
- 左上角显示当前版本，并支持检查 GitHub Release；发现新版本时显示紧凑更新提示。

## 下载说明

- 本次已验证并提供 macOS Apple Silicon（M1、M2、M3、M4）、macOS Intel 和 Windows x64 版本。
- macOS 包当前未签名；首次打开如被系统拦截，可在系统设置中允许，或右键 CrewFlow.app 后选择“打开”。
- Windows 版解压后运行文件夹内的 CrewFlow.exe，请保留整个解压目录；如被 SmartScreen 提示，请核对下载来源后选择继续运行。
- 正常替换应用不会删除数据，单人数据和团队服务数据均保存在应用程序目录之外。
