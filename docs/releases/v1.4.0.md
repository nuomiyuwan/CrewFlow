# CrewFlow v1.4.0

发布日期：2026 年 7 月 30 日

## 本次更新

- 任务面板新增“全部、今天、本周、指定日期”筛选，可以快速定位目标任务。
- 交付日历支持长按计划并拖到其他日期；移动后会同步更新项目下一节点、延期和风险状态。
- 单日计划过多时可以通过“更多”弹层完整查看，不再挤满日历格。
- 项目支持一个主资料路径和多个附加路径，归档项目也能分别打开。
- 项目任务新增“完成实证资料”文件夹，只保存文件夹路径，不向数据库复制大型文件。
- 团队负载卡新增参与项目和当前流程节点，便于判断每个人正在推进到哪一步。
- 新建项目中的两个客户字段标题支持全局改名，可适配“大客户、合作单位”等不同行业叫法。
- 首页“今日任务”同时考虑今天到期、制作中和修改中的任务。
- 未录入财务的活动项目会纳入待结款提醒，直到明确标记为已结算。
- 优化页面与内部列表的滚动衔接、任务资料区域布局、全局路径搜索及手动更新说明。
- 使用说明新增 OpenRouter 免费模型注册、API Key 和免费模型配置流程。

## 团队模式升级建议

1. 先备份常驻主机上的团队数据库。
2. 优先更新常驻主机上的 CrewFlow，再更新其他电脑。
3. 确认团队服务正常后，测试登录、项目读取和保存。
