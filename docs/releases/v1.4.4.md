# CrewFlow v1.4.4

发布日期：2026-08-13

## 本次更新

- 项目经理可以编辑自己负责的未归档项目，并新增、修改、分配或删除项目执行任务。
- 交付日历中已有节点的“编辑”窗口新增计划日期，改期后自动重新计算项目的延期和风险状态。
- 团队主机现在对多台电脑的写入请求排队处理。
- 多人同时修改不同项目、任务或节点时会自动合并，不再因数据版本变化丢失本次操作。
- 两人同时修改同一条数据时仍会阻止后写覆盖，保留安全的冲突提示。
- 团队保存因网络或主机故障失败时，界面会明确显示失败信息。

## 安装包

- `CrewFlow-v1.4.4-macOS-universal.dmg`：Apple Silicon 与 Intel Mac 通用安装包。
- `CrewFlow-v1.4.4-Windows-x64-Setup.exe`：64 位 Windows 10/11 安装程序。

Windows 应用内更新还会使用同一 Release 中的 `latest.yml` 和 `.blockmap` 文件，请勿单独删除。

## 更新说明

- 团队主机应优先更新，新版启动后会自动修复并恢复后台团队服务。
- 其他电脑建议同步更新到 `v1.4.4`，以使用新的安全重试与权限逻辑。
- 单人数据、团队数据库和助理 API Key 都保存在安装目录之外，正常更新不会清空数据。
