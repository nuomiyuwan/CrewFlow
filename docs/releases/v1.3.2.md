# CrewFlow v1.3.2

发布日期：2026 年 7 月 28 日

## 本次更新

- CrewFlow 助理可以识别自然语言中的新建项目、项目状态调整、任务分派和交付节点意图，并打开原有表单完成预填。
- 所有数据修改仍需用户在原界面确认，并继承当前登录账号的权限。
- 在线多模态模型支持选择、拖入或粘贴图片，可从聊天截图、排期截图和节点截图中整理信息。
- 本地 Ollama 模型支持自动读取已安装模型，并可选择快速响应或深度思考。
- 助理快捷问题会根据当前页面、风险、任务、日历和财务数据动态调整。
- 交付日历的项目列表和节点列表改为独立滚动，内容较多时不再无限拉长整个页面。
- 日历节点改期或删除后，项目关键日期、下一节点、延期状态和风险统计会自动重新计算。
- 修复助理横向滚动条、发送后输入焦点丢失，以及部分顶部区域无法稳定拖动窗口的问题。

- `CrewFlow-v1.3.2-macOS-arm64-20260728.zip`：Apple 芯片 Mac。
- `CrewFlow-v1.3.2-macOS-x64-20260728.zip`：Intel 芯片 Mac。
- `CrewFlow-v1.3.2-Windows-x64-20260728.zip`：64 位 Windows。
- macOS 包当前未签名，首次打开如被系统拦截，可右键 `CrewFlow.app` 后选择“打开”。
