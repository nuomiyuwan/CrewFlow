# CrewFlow v1.4.1

发布日期：2026 年 7 月 31 日

## 本次更新

- CrewFlow 助理新增项目健康度、流程状态、项目负责人、任务状态、天气城市、上下班时间和页面跳转等确认式操作。
- 助理可以结合内置使用说明回答常见的软件使用问题。
- 助理继续继承当前登录账号的可见范围和编辑权限，所有修改均先打开确认窗口；删除、账号密码、财务金额、API Key、数据导入和清空等敏感操作不开放。
- 财务结算状态与开票、收款进度联动；已开票但仍有未收金额时显示“待收款”。
- 项目进度改为根据当前流程节点所在位置计算，已完成或已归档项目保持 100%。
- 修复纯数字常用选项无法添加的问题，例如年份 `2026`。
- 修复交付日历单日节点过多时弹窗被遮挡、内容不可见或无法正常拖动的问题。

- `CrewFlow-v1.4.1-macOS-x64-20260731.zip`：Intel 芯片 Mac。

- macOS 包当前未签名，首次打开如被系统拦截，可右键 `CrewFlow.app` 后选择“打开”。
- Windows 版必须完整解压后运行 `CrewFlow.exe`，不要拆散程序目录。
- 正常替换应用不会删除数据；单人数据和团队数据库均保存在应用目录之外。

## 团队模式升级建议

1. 先备份常驻主机上的团队数据库。
2. 优先更新常驻主机上的 CrewFlow，再更新其他电脑。
3. 确认团队服务正常后，测试登录、项目读取和保存。
