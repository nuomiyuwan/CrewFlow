# CrewFlow v1.4.3

发布日期：2026-08-08

## 本次更新

- 新增 macOS 通用 DMG 安装包，同时兼容 Apple Silicon 和 Intel Mac。
- 新增 Windows Setup 安装程序，并支持在 CrewFlow 内下载更新、安装并重启。
- 更新弹窗现在显示新版本内容、安装步骤、下载状态和进度。
- 团队主机只在正式安装时短暂停止服务；新版启动后自动修复服务路径并恢复运行。
- 首次从 Windows ZIP 版迁移到安装版时继续读取原有系统数据目录，确认新版正常后可删除旧程序文件夹。
- macOS 可在应用内下载并打开 DMG，退出旧版后拖入“应用程序”完成覆盖。
- 更新中文使用说明中的安装、迁移、团队主机和无签名程序提示。
- 修复更新地址校验和团队服务识别边界，并更新存在安全公告的间接依赖。

## 安装包

- `CrewFlow-v1.4.3-macOS-universal.dmg`：Apple Silicon 与 Intel Mac 通用安装包。
- `CrewFlow-v1.4.3-Windows-x64-Setup.exe`：64 位 Windows 安装程序。

Windows 自动更新还会使用同一 Release 中的 `latest.yml` 和 `.blockmap` 文件，请勿单独删除。

## 更新说明

- 旧版 ZIP 用户第一次需要手动下载并运行 `v1.4.3` 安装包；从本版本开始，Windows 后续版本可在软件内完成下载和安装。
- macOS 当前未使用 Apple Developer ID 签名，因此仍需手动确认来源并覆盖应用；该限制不影响数据保留。
- 单人数据、团队数据库和助理 API Key 均保存在程序目录之外，正常安装不会清空数据。
